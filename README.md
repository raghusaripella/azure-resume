# BI Brain INC Website

This repository contains a simple static website for BI Brain INC, a data engineering, BI, and IT consulting firm.

## Project files

- `index.html` — landing page for the website
- `styles.css` — styling for the site
- `Profile.pdf` — professional profile content used as source material

## Preview locally

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
